# Laraib's Foundation

Build a professional single-page developer portfolio website from scratch for Laraib Amjad.

This is the foundation step only. Create the overall design system, page structure, navigation, background, typography, spacing system, and responsive foundation.

Do not over-design the website yet.

Do not add unnecessary animations.

Do not use gradients.

==================================================

DESIGN DIRECTION

==================================================

The website should feel like a real professional full-stack developer portfolio.

Visual personality:

- Technical

- Minimal

- Editorial

- Modern

- Professional

- Confident

It should NOT look like:

- a university assignment

- a generic resume template

- an AI-generated landing page

- a SaaS website

- a colorful portfolio template

The design should rely on typography, spacing, grid structure, borders, alignment, and hierarchy rather than decorative effects.

==================================================

COLOR SYSTEM

==================================================

Light mode should be the primary design.

Background:

#FAFAFA

Primary text:

#111111

Secondary text:

#666666

Borders:

#E5E5E5

Surface:

#FFFFFF

Accent:

#2563EB

Hover accent:

#1D4ED8

Do not use gradients.

Do not introduce additional bright colors unless necessary.

==================================================

BACKGROUND

==================================================

Use #FAFAFA as the main background.

Add a very subtle technical grid pattern across selected large sections.

The grid should be extremely subtle, around 3–5% visual intensity.

The grid should feel similar to a developer workspace or technical design system.

It must never distract from the content.

Do NOT use:

- gradient backgrounds

- animated gradients

- glowing backgrounds

- floating particles

- decorative blobs

- neon effects

- glassmorphism

==================================================

TYPOGRAPHY

==================================================

Use Inter as the primary font.

Use a clean monospace font for technical metadata, labels, project numbers, dates, and technology tags.

Typography should create the visual personality of the website.

Use:

- large bold headings

- clear section headings

- readable body text

- small uppercase metadata

- monospace technical labels

Avoid decorative fonts.

==================================================

LAYOUT

==================================================

Use a maximum content width of approximately 1200px.

Create a consistent 12-column grid system.

Maintain consistent left and right margins throughout the website.

Use generous but controlled whitespace.

Do NOT create unnecessarily tall sections.

Sections should be content-driven.

Use thin borders for visual separation.

Do not put every section inside a rounded card.

==================================================

NAVIGATION

==================================================

Create a clean sticky navigation bar.

Left:

LA.

Use "LA." as the simple personal mark.

Right:

HOME

ABOUT

SKILLS

PROJECTS

EXPERIENCE

CONTACT

Add a simple dark/light mode toggle on the right.

Navigation should have:

- white/off-white background

- thin bottom border

- clean typography

- subtle hover states

On mobile, convert the navigation into a clean hamburger menu.

==================================================

PAGE STRUCTURE

==================================================

Create these sections in this exact order:

1. Hero

2. About

3. Skills

4. Projects

5. Experience

6. Education

7. Services

8. Contact

9. Footer

Do not fill all sections with detailed content yet.

This first step is mainly about establishing the visual system and structure.

==================================================

RESPONSIVE FOUNDATION

==================================================

Build mobile-first responsive behavior.

The website must work properly on:

- desktop

- laptop

- tablet

- mobile

Prevent horizontal scrolling.

Maintain proper typography and spacing on smaller screens.

==================================================

ANIMATION FOUNDATION

==================================================

Keep animations minimal.

Only establish basic transition behavior for:

- links

- buttons

- navigation

- theme toggle

Do not add scroll animations, parallax, particles, or complex animations yet.

==================================================

IMPORTANT

==================================================

This is the FOUNDATION step.

Do not try to make every section impressive yet.

First establish:

- visual identity

- typography

- colors

- background

- grid

- navigation

- spacing

- responsive structure

- section order

Keep the implementation clean and maintainable.

Do not invent personal information or project information.

We will build and refine each section separately in later steps.
